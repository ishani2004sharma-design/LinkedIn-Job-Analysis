# LinkedIn Job Market Analysis 📊

An end-to-end data analytics project focused on exploring LinkedIn job postings to understand hiring trends, in-demand skills, job locations, experience requirements, and company hiring patterns.

This project combines **Selenium Web Scraping, Python, Data Cleaning, Exploratory Data Analysis (EDA), Microsoft Excel, Power BI, and Streamlit** to transform job posting data into meaningful insights and an interactive job market exploration experience.

## 🎯 Project Objective

The main objective is to analyze Data Analyst job opportunities and identify the skills, locations, companies, and experience levels commonly required by employers. The project aims to help job seekers better understand market expectations and make informed career decisions using data-driven insights.

## 🛠️ Technologies Used

- **Python** – Data processing, cleaning, and analysis
- **Selenium** – Automated web scraping of job postings
- **Pandas** – Data manipulation and preprocessing
- **NumPy** – Numerical operations where required
- **Jupyter Notebook** – Data exploration and analysis
- **Microsoft Excel** – Pivot tables, summaries, and reporting
- **Microsoft Power BI** – Interactive dashboards and visual analytics
- **Streamlit** – Interactive web application development
- **Git & GitHub** – Version control and project hosting

## 🔄 Project Workflow

1. **Web Scraping:** Collected LinkedIn job posting information using Selenium.
2. **Data Cleaning:** Processed the collected data, handled missing values, checked duplicate records, and prepared datasets for analysis using Python and Pandas.
3. **Exploratory Data Analysis:** Examined job roles, companies, locations, experience requirements, and skill demand to identify patterns in the collected data.
4. **Skills Analysis:** Analyzed skills mentioned in job descriptions to identify frequently requested technical and professional skills.
5. **Excel Analysis:** Used pivot tables and summaries to explore job distributions and hiring patterns.
6. **Power BI Visualization:** Developed interactive dashboards to present key metrics and job market insights.
7. **Streamlit Application:** Built an interactive web app that allows users to explore job opportunities using filters, charts, summary metrics, and skill-based selection.
8. **Deployment:** Prepared the Streamlit application for online access and portfolio demonstration.

## 🚀 Run the Streamlit Application Locally

**1. Clone the repository**

```bash
git clone https://github.com/ishani2004sharma-design/LinkedIn-Job-Analysis.git
cd LinkedIn-Job-Analysis
```

**2. Install the required dependencies**

```bash
pip install -r requirements.txt
```

**3. Run the application**

```bash
python -m streamlit run "Streamlit App/app.py"
```

The application should open in your browser. If it does not, visit:

`http://localhost:8501`

Ensure that the required cleaned CSV files are available at the paths expected by the application.
